GPS CLOCK STEPPER DRIVER PCB - DETAILED SCHEMATIC
==================================================

POWER INPUT SECTION
-------------------
J1: 24V Power Connector (2-pin, 2.54mm spacing)
  Pin 1: +24V_IN
  Pin 2: GND

D1: 1N4007 Diode (Reverse Polarity Protection)
  Anode: +24V_IN
  Cathode: +24V_RAIL
  Purpose: Protect against reverse polarity connection

F1: 10A Fuse (radial or cartridge)
  Series with +24V to protect entire circuit
  Recommended: T10 or 10A rated for 24V

C1: 470µF 50V Electrolytic Capacitor
  +: +24V_RAIL
  -: GND
  Purpose: Bulk capacitance for transient response

C2: 100nF Ceramic Capacitor
  Between +24V_RAIL and GND (close to buck converter)
  Purpose: High-frequency filtering


BUCK CONVERTER SECTION (24V → 5V)
---------------------------------
Buck IC: MP1584 or equivalent (SOIC-8 package)

Input Side:
  VIN: +24V_RAIL (with 100nF cap C2)
  GND: GND

Output Side:
  VOUT: +5V_RAIL
  GND: GND

Support Components:
  L1: 10µH Inductor (1.5A rated)
  C_in: 10µF 50V Ceramic (input, before inductor)
  C_out: 100µF 10V Ceramic + 10µF 10V Ceramic (output)
  C_out: 1µF 10V Ceramic (high-frequency output filter)

Feedback Network (for 5V output):
  R1: 1MΩ resistor (feedback divider, top)
  R2: 240kΩ resistor (feedback divider, bottom)
  Connection: (R1 top to VOUT, R1-R2 junction to FB pin)
  Adjust R2 for exact output voltage if needed


STEPPER DRIVER ARRAY (×6)
------------------------

Each driver section follows this pattern (repeat 6 times):

TMC2208_N (SOIC-16 package)
  Pins:
    VIO: +5V (logic supply)
    GND: GND (multiple pins - all connected)
    VM: +24V_RAIL (motor supply)
    OUT1, OUT2: Motor phase A
    OUT3, OUT4: Motor phase B
    STEP: From Pico GPIO
    DIR: From Pico GPIO
    DIAG: Optional diagnostic output
    UART RX: Optional (not used in basic mode)
    SENSE (pin 5, 6): For current limiting

Per-Driver Support (repeat for each driver):

  Power Decoupling:
    C_vm1: 100µF 50V Electrolytic (on VM line, bulk)
    C_vm2: 10µF 10V Ceramic (on VM line, mid-freq)
    C_vm3: 100nF Ceramic (on VM line, high-freq)
    C_vio: 100nF Ceramic (on VIO line)

  Current Sense Resistor:
    R_sense: 0.11Ω (shunt resistor across current sense pins)
    C_sense: 10nF Ceramic (across sense resistor for filtering)
    Purpose: Sets motor current (I_RMS = V_sense / (5 × R))
    V_sense = 0.325V nominal for default current

  Pull-down Resistors (for signal integrity):
    R_step_pd: 10kΩ pull-down on STEP input
    R_dir_pd: 10kΩ pull-down on DIR input
    Purpose: Ensure known state if Pico pin floating


MOTOR CONNECTORS
----------------
6× J_Motor (4-pin connectors for each motor)
  Pin 1: Motor_A_Phase1 → OUT1 of TMC2208
  Pin 2: Motor_A_Phase2 → OUT2 of TMC2208
  Pin 3: Motor_B_Phase1 → OUT3 of TMC2208
  Pin 4: Motor_B_Phase2 → OUT4 of TMC2208

Recommended: JST XH 2.54mm or Molex KK 2.54mm


PICO CONNECTOR
--------------
J_Pico: 40-pin header or custom connector
  Required connections:
    GPIO0 (pin 1): GPS TX
    GPIO1 (pin 2): GPS RX
    GPIO2-GPIO15: Stepper control pins (STEP/DIR pairs)
    GPIO17: TFT CS
    GPIO18: TFT SCK
    GPIO19: TFT MOSI
    GPIO20: TFT DC
    GPIO21: TFT RST
    GPIO26: Timezone button
    GPIO27: 24H button
    3V3 (pin 36): +5V_RAIL (via 100Ω resistor for current limit)
    GND (multiple): GND

Voltage Note: Pico runs at 3.3V internally, but 5V tolerant on digital inputs
Use pull-up resistors on STEP/DIR for noise immunity


STEPPER ASSIGNMENTS
-------------------
Motor 0 (Hours Tens):   GPIO12 (STEP), GPIO15 (DIR)
Motor 1 (Hours Ones):   GPIO10 (STEP), GPIO14 (DIR)
Motor 2 (Minutes Tens): GPIO8 (STEP), GPIO15 (DIR)
Motor 3 (Minutes Ones): GPIO6 (STEP), GPIO14 (DIR)
Motor 4 (Seconds Tens): GPIO4 (STEP), GPIO15 (DIR)
Motor 5 (Seconds Ones): GPIO2 (STEP), GPIO14 (DIR)

Note: Verify GPIO assignments match Configuration.h


CONNECTIVITY SUMMARY
--------------------
Power Plane:     +24V_RAIL, +5V_RAIL, GND (ground plane across entire PCB)
Signal Integrity: All STEP/DIR signals with 100Ω series resistors + 10kΩ pull-downs
Return Paths:    All GND connections to ground plane (multiple vias)
