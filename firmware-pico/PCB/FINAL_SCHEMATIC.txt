POWER DISTRIBUTION SUMMARY:

24V Input
  │
  ├─ 10A Fuse ─ 1N4007 Diode ─┐
  │                            │
  └─ +24V_RAIL ────────────────┼─── To 6× Stepper Modules
                                │
                             Buck Converter Module (pre-built)
                             (24V in → 5V out)
                                │
                              +5V_RAIL ──── To Pico & Display

GND ────────── To all modules (continuous ground plane)


COMPONENT PLACEMENT NOTES:

Zone 1: Input Protection (left edge)
  - Fuse near input
  - Diode after fuse
  - Bulk cap C1 immediately after diode

Zone 2: Buck Converter Area (left-center)
  - Mount buck converter module
  - Output filtering caps C3, C4, C5 very close to module output

Zone 3: Stepper Distribution (right side)
  - 6 connector headers for stepper modules
  - 24V and GND routed on heavy traces to each header
  - Direct connections (short, wide traces)

Zone 4: Signal Routing (center to right)
  - Series resistors (R1-R6) near Pico end
  - Pull-down resistors (R7-R12) near stepper module headers
  - Ground vias between Pico and stepper modules

Zone 5: Pico Connector (top)
  - 40-pin header for Pico
  - TFT display connector (4-5 pins)
  - GPS module connector (if separate from Pico)


KEY DESIGN DECISIONS:

1. NO complex ICs - just passive components
2. Buck converter is pre-built module (not bare IC)
3. All stepper drivers on separate pre-built boards
4. Minimal PCB - mainly routing and filtering
5. Signal protection is OPTIONAL but recommended
6. All 2.54mm connectors (standard pitch)


ELECTRICAL CHARACTERISTICS:

24V Input Protection:
  - 1N4007 diode: 1A max, 1000V rating (protects against reverse polarity)
  - 10A fuse: Breaks circuit if >10A drawn
  - 470µF bulk cap: Handles inrush current, smooths supply

5V Filtering:
  - 100µF bulk cap: Low-frequency smoothing
  - 10µF cap: Mid-frequency noise rejection
  - 100nF cap: High-frequency noise filtering
  (All three together = good power supply quality)

Signal Protection (Optional):
  - 100Ω series resistor: Limits current if short circuit
  - 10kΩ pull-down: Defines default state (LOW)
  - Together: Noise immunity + protection

Current Budget:
  - Pico: ~100mA
  - Display: ~50mA
  - GPS module: ~30mA
  - Logic: ~30mA
  - Total: ~210mA from 5V (buck converter must supply ≥250mA)

  - Stepper modules: Draw 24V directly
  - No current limit needed on 24V (supplied by main PSU)


TESTING CHECKLIST:

Before applying power:
  ☐ Continuity test: 24V rail (should be continuous)
  ☐ Continuity test: 5V rail (should be continuous)
  ☐ Continuity test: GND plane (everywhere)
  ☐ Resistance: 24V to GND (should be >10kΩ)
  ☐ Resistance: 5V to GND (should be >10kΩ)
  ☐ Visually inspect all solder joints

After power applied:
  ☐ Measure 24V rail (should be 24V ±0.5V)
  ☐ Measure 5V rail from buck (should be 5.0V ±0.25V)
  ☐ Check buck converter is not hot (should be warm, not hot)
  ☐ Connect Pico - should boot normally
  ☐ Test each stepper module independently
  ☐ Test STEP/DIR signals with multimeter or scope


THIS IS AN ELEGANT MINIMAL DESIGN!

You're essentially building a routing PCB that:
✓ Filters power supply noise
✓ Routes signals cleanly
✓ Provides connectors for modules
✓ Protects against reversed polarity
✓ Requires no complex assembly
✓ Uses readily available components

The actual "brains" are handled by your pre-built modules.
This board just makes the whole system work together reliably.
